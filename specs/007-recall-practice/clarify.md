# 007 clarify
- "Recognition" = an item answered by picking from given choices first. A "type it first" item asks for recall first;
  the choices are only a fallback, so it is counted as recall (reported separately as "type it first").
- Marking: capitals, punctuation, curly quotes and a leading a/an/the don't matter; number words = digits (0–20).
  One letter off (5+ letters) gets one friendly "So close" nudge, then it counts as a miss and the choices appear.
- A right pick after "Show choices" counts as right, like before (no pass-mark change, no harder lessons).
- Which items: deterministic (a hash of the item), so the same items are "type it first" on every device and in tests.
- Not in boss/dragon rounds (timers), crown checks keep the same items (so a check can be type-first too: fine, it's recall).
- Classic-only test runs (window.__WR_CLASSIC_ONLY) keep plain choices.
- Wave 2 (later, not now): more dictation and spelling from memory at B1+ listening/reading, where answers are paraphrased.
